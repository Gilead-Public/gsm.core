# Articles

### Articles

- [Cookbook](https://gilead-biostats.github.io/gsm.core/dev/articles/Cookbook.md):

  Sample code showing how to use the Good Statistical Monitoring {gsm}
  suite of packages using sample data from {gsm.core}.

- [Step-by-Step Analysis
  Workflow](https://gilead-biostats.github.io/gsm.core/dev/articles/DataAnalysis.md):

  This vignette walks users through the mechanics of the functions that
  produce all of the Analysis workflow output within the
  [gsm.core](https://gilead-biostats.github.io/gsm.core) package.

- [Data
  Model](https://gilead-biostats.github.io/gsm.core/dev/articles/DataModel.md):

  A vignette detailing the data model used in the gsm pipeline.

- [gsm
  Extensions](https://gilead-biostats.github.io/gsm.core/dev/articles/gsmExtensions.md):

  This vignette describes how to extend {gsm.core} by creating new
  ‘modules’, including metrics, reports and shiny apps that can be run
  using the standard gsm pipeline.

- [KRI
  Method](https://gilead-biostats.github.io/gsm.core/dev/articles/KRIMethod.md):

  This vignette outlines the statistical methods used to evaluate Key
  Risk Indicators (KRIs) in {gsm}.
