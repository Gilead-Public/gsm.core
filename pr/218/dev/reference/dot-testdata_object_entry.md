# One object's entry in a release's snapshot.json

One object's entry in a release's snapshot.json

## Usage

``` r
.testdata_object_entry(tag, object)
```

## Arguments

- tag:

  `character(1)` Release tag, e.g. `"data-8cde53949d4d"`.

- object:

  `character(1)` Object name.

## Value

`list` With `file` and `digest`.
