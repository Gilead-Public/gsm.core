# reportingResults_study Dataset

**\[stable\]**

## Usage

``` r
reportingResults_study
```

## Format

A data frame with 6 rows and 10 columns:

- GroupID:

  grouping variable

- GroupLevel:

  level of grouping variable

- Numerator:

  number of flags in group

- Denominator:

  total subjects in group

- Metric:

  calculated rate/metric value

- Score:

  statistical score

- Flag:

  ordinal flag to be applied

- MetricID:

  unique metric identifier

- StudyID:

  unique study identifier

- SnapshotDate:

  date of the snapshot

## Source

Generated from `reportingResults_study.csv` dataset in the `gsm.core`
package.
