# Folder for one local build

Folder for one local build

## Usage

``` r
.testdata_local_dir(installed)
```

## Arguments

- installed:

  `list` Output of
  [`package_versions()`](https://gilead-public.github.io/gsm.core/dev/reference/package_versions.md).

## Value

`character(1)` The build folder for `installed`.
