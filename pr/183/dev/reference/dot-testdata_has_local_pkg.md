# Is any indexed package installed or loaded without a `RemoteSha`?

Is any indexed package installed or loaded without a `RemoteSha`?

## Usage

``` r
.testdata_has_local_pkg(installed)
```

## Arguments

- installed:

  `list` Output of
  [`package_versions()`](https://gilead-public.github.io/gsm.core/dev/reference/package_versions.md).

## Value

`logical(1)`
